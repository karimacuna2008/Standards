# Python Standards — INDEX

Lee este archivo primero para saber qué estándar usar según la tarea.

| Archivo | Cuándo usarlo |
|---|---|
| `code-standards.md` | Nombrado de variables, funciones, clases; estilo PEP 8; estructura general de un script |
| `functions.md` | Cómo escribir funciones: firmas, type hints, docstrings, retornos |
| `api-client.md` | Consumir APIs REST externas: HTTP client, autenticación, manejo de respuestas |
| `automation.md` | Scripts automatizados, bots, tareas programadas, ejecución por CLI |
| `error-handling.md` | Excepciones, logging, propagación de errores, mensajes de error |
| `configuration.md` | Variables de entorno, archivos .env, gestión de configuración |
| `project-structure.md` | Estructura de carpetas, organización de módulos, layout del proyecto |
| `testing.md` | Tests con pytest, organización de tests, convenciones |
| `data-analysis.md` | EDA, carga y limpieza de datos (en progreso) |

> Cuando crees un nuevo estándar Python, agrégalo a esta tabla antes de cerrar la sesión.
