# Python Standards — INDEX

| `data-analysis.md` | EDA, inspección, limpieza, análisis univariado/bivariado y visualización |

| `api-server.md` | Arquitectura de servidores FastAPI: main.py, routers modulares, CORS dinámico |
| `databases.md` | Bases de datos relacionales en Python: SQLAlchemy 2.0, mixins y migraciones Alembic |

| `cloud-services-gcp.md` | Integración GCP: Firestore, Cloud Storage, Firebase Auth, Cloud Logging, Cloud Build deploy |

| `api-security.md` | Seguridad de API: comparación de tokens, auth de endpoints/webhooks, validación de payload |
