# Prompt-Driven Development Standards — INDEX

Read this file first to know which standard to use for the task.

| File | When to use it |
|---|---|
| `kickoff.md` | Starting a brand-new project under this standard, or resuming an existing one with no context loaded yet |
| `project-structure.md` | Setting up a new project's folder layout, or checking where a given artifact belongs |
| `workflow.md` | Running a batch of prompts/changes: the draft → validate → checklist cycle |
| `prompts.md` | Writing prompts for an external code-generation tool (e.g. AI Studio) |
| `architecture.md` | Component/file organization, design tokens, tracking backend/external gaps |
| `responsive-audit.md` | Auditing visual/layout behavior across screen widths and font scaling, module by module |
| `spec-and-plan-gate.md` | Deciding whether a change needs brainstorming+writing-plans or can go direct |

> When creating a new standard file here, add it to this table before closing the session.
